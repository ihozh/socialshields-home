Social Shields

An ecosystem for security research, education, and products. We build tools that give students hands-on resources and deliver practical solutions for public services.

Farmingdale State College

Hi there! New here? Start with C.I.A. Triad, the three goals every security decision protects.

Research

  • MHDash: AI research for suicide prevention, with a live dataset and a benchmark.
  • SIEGE: A proof-of-work blockchain built for security classes.

Education

  • Knowledge Base: Articles and knowledge maps for the courses we teach.
  • Labs: Hands-on labs and open playgrounds, from logic gates to cryptography.
  • PyRam: Write, run and practice Python in your browser.
  • Ramux: A small Linux computer with a desktop, running in your browser.
  • Unpaged: Interactive lecture decks that follow the instructor in class.

Products

  • News Hub: A news crawler API with search and a live stream.
  • News: A live, searchable feed of the news it collects.
  • Icons: Isometric animated SVG icons, by copy or by API.
